IP Widget

A native macOS desktop widget showing your public IPv4 address, country name, and flag in the standard small widget size.

  • Immediately reacts to system network configuration and default-route changes, including Wi-Fi, Ethernet, and VPN switches.
  • Requests fresh data on network changes and approximately every four minutes. WidgetKit controls final rendering.
  • Choose 2ip.io or icanhazip.com as the preferred IP service; the other is used as fallback. The companion shares its result with the widget through a local file.
  • Shows a synthetic IP reputation scale and VPN/proxy indicator. Successful ratings are cached for 24 hours per IP.
  • Reputation is a heuristic and does not guarantee access to any service.
  • Shows clear offline and service-unavailable states.
  • Data older than five minutes prompts you to launch IP Widget. Click the widget to open the app.

After installation: open IPWidget in Applications. The companion app runs in the menu bar. Keep it running for network-change monitoring.

Add the widget: right-click the desktop, choose Edit Widgets, search for IP Widget, and add the small widget.

Requires macOS 26 or later and an Apple Silicon Mac.

This build is ad-hoc signed. The installer is unsigned and not notarized; macOS may block installation or execution on other Macs.

IP Geolocation by DB-IP — https://db-ip.com. Country Lite data is licensed under CC BY 4.0 and converted to a compact IPv4-only format.
